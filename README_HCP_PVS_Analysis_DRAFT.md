## Overview

This repository contains Python/Jupyter Notebook workflows for processing and analysing perivascular spaces (PVS) in brain MRI data from the Human Connectome Project (HCP).
PVS are fluid-filled spaces surrounding cerebral blood vessels. On structural MRI, they typically appear hyperintense on T2w images and hypointense on T1w images.

The project includes modality-specific image-processing pipelines for:
- **T1-weighted MRI (T1)**
- **T2-weighted MRI (T2)**
- **EPC MRI (Enhanced Perivascular Contrast):** Generated by voxel-wise division of the denoised T1-weighted image by the denoised T2-weighted image (EPC = T1w / T2w).

*note: Before generating EPC, the T1w and T2w images must be spatially aligned and have matching image dimensions, voxel spacing, and spatial geometry.


The workflows include image preprocessing, PVS-related image filtering and segmentation, periventricular exclusion, quantitative measurements, visualisation, and statistical analysis.

The repository is intended to share the research code. **MRI data, participant-level input files, and generated results are not included.**

### Image Space, Dimensions, and Spatial Alignment

The HCP preprocessing pipeline provides the preprocessed T1w, T2w, and aseg+aparc images in native space. The dimensions of the preprocessed T1w and T2w images correspond to those of their respective raw images.

**Important consideration for quantitative analysis:** Before performing voxel-wise PVS measurements, users should ensure that the following images are spatially compatible:

- Binary PVS mask.
- White matter (WM) mask.
- Corresponding intensity image (T1w, T2w, or EPC).

The images should have matching dimensions and spatial alignment, including voxel spacing, orientation, and spatial origin. This is necessary to ensure that the masks are applied to the correct voxels in the corresponding intensity images.

For EPC generation, the denoised T1w and T2w images should also be spatially aligned and have matching dimensions before voxel-wise division (EPC = T1w / T2w).

### Neuroradiologist-associated slice information: `Wardlaw_HCP.csv`

The T2 and EPC notebooks use a local input file named `Wardlaw_HCP.csv` for the 2D PVS feature analysis.

The file contains participant identifiers, modality-specific right- and left-sided Wardlaw rating fields, and slice indices associated with centrum semiovale assessments.

In the current `compute_2d_pvs_metrics()` implementation:

1. The participant is matched using `subject_id`.
2. The function retrieves `slice_num_CS` from `Wardlaw_HCP.csv`.
3. That slice is extracted from the PVS mask, white-matter mask, and corresponding MRI volume.
4. 2D PVS measurements are calculated on the selected slice.

**Important:** the current function uses `slice_num_CS`. Although the CSV also contains `slice_num_BG`, the shown function does not currently use that field. The function uses the selected slice index; it does not use the numerical Wardlaw rating columns in the feature calculations themselves.

2. Wardlaw Scoring System
### Wardlaw Visual Rating System

The Wardlaw visual rating system was used for neuroradiological assessment of PVS in the HCP dataset.

The general Wardlaw scale evaluates PVS severity in three anatomical regions: the centrum semiovale, basal ganglia, and midbrain.
For the centrum semiovale and basal ganglia, scores range from 0 to 4:
- 0: No visible PVS
- 1: 1–10 PVS
- 2: 11–20 PVS
- 3: 21–40 PVS
- 4: More than 40 PVS

For the midbrain, the score is binary:
- 0: PVS absent
- 1: PVS present

Through this project, the neuroradiologist evaluated the centrum semiovale using T2w and EPC images. An axial slice with the highest number of visible PVS was selected for each region by the neuroradiologist.

PVS were counted separately in the left and right hemispheres. The higher of the two hemispheric scores was retained as the final score for each anatomical region.
The scores are region-specific, rather than one combined score across all anatomical regions.
The original Wardlaw scale was used.

## Workflow
Run the notebooks in the following order, subject to the dependencies of the final pipeline:
1. **T1 pipeline** — process T1-weighted MRI and generate the required PVS measurements.
2. **T2 pipeline** — process T2-weighted MRI. The 2D feature analysis uses the participant-specific centrum semiovale slice index from `Wardlaw_HCP.csv`.
3. **EPC pipeline** — process EPC MRI. The 2D feature analysis also uses the participant-specific centrum semiovale slice index from `Wardlaw_HCP.csv`. 
4. **Statistical analysis** — load the generated measurement tables and perform the planned statistical comparisons and models.

Dependencies between these three pipelines: 
In the 'T1 pipeline' the T1w image is denoised, the white matter mask is extracted. This white matter mask will be used in 'T2 pipeline' and 'EPC pipeline' as ROI mask. 
In the 'T2 pipeline' the T2w image is denoised.
In the 'EPC pipeline' the denoised T2w and T1w images are used to create EPC (EPC= T1w / T2w).
The EPC pipeline depends on the T1 and T2 pipelines having been run first; otherwise, the corresponding T1 and T2 measurements in the combined metrics table may remain empty.


## Quantitative measurements

The notebooks calculate PVS-related measurements. Depending on the modality and analysis, these include:

- PVS count: Number of individual PVS components (excluding components smaller than 2 voxels).
- Mean PVS diameter: Mean Equivalent Spherical Diameter (ESD), reported in voxels and/or millimeters.
- PVS volume: Total PVS volume (mm³).
- PVS volume fraction: Ratio of total PVS volume to total WM volume.
- PVS-to-white-matter intensity ratio: Ratio of mean PVS intensity to mean white matter intensity.
- PVS–WM contrast (z-score): Mean z-scored intensity of PVS voxels after normalization within the white matter mask.
- 2D area-based measurements: PVS area measurements on the neuroradiologist-associated slice. As Wardlaw scores are obtained based on one slice (2D), we decided to consider that slice for calculating PVS metrics and calculate correlation between Wardlaw score and each PVS metric for each subject.
Intensity-based contrast metrics are calculated separately for T1w, T2w, and EPC images.

Methodological Details: (diameter measurements as ESD)
- 3D connectivity: label(pvs_data, connectivity=3) uses 26-connectivity in 3D.
- 2D connectivity: label(pvs_slice, connectivity=1) uses 4-connectivity in 2D.
- 3D diameter: You calculate equivalent spherical diameter (ESD).
- 2D diameter: You calculate equivalent circular diameter from the component area. This is not the same as 3D ESD.
- 3D measurements: You calculate PVS count, mean diameter, PVS volume, PVS-to-WM volume fraction, intensity ratio, and z-scored contrast.
- 2D measurements: You calculate PVS count, mean diameter, PVS area, WM area, PVS-to-WM area fraction, intensity ratio, and z-scored contrast.

component-size thresholds:
- 3D PVS count and diameter: components smaller than 5 voxels are excluded.
- 2D PVS count and diameter: components smaller than 2 pixels are excluded.
- PVS area and intensity measurements: all foreground voxels in the original binary PVS mask are used.

## Statistical Analysis

Statistical analyses were performed to compare PVS measurements across T1w, T2w, and EPC modalities.

The analyses included:

- Shapiro–Wilk tests to assess the normality of paired differences.
- Paired t-tests or Wilcoxon signed-rank tests for selected pairwise comparisons (EPC vs T1 and EPC vs T2).
- Repeated-measures ANOVA or Friedman tests for overall comparisons across the three MRI modalities.
- Greenhouse–Geisser correction for repeated-measures ANOVA when the sphericity assumption was violated.
- Bonferroni correction for the pairwise post-hoc comparisons following repeated-measures analysis.
- Pearson or Spearman correlation analyses, depending on data normality.
- Linear mixed-effects models to account for repeated measurements and subject-level variability.

The mixed-effects models included imaging modality, age (treated as a categorical variable), gender (treated as a categorical variable), and intracranial volume as fixed effects, with subject ID as a random effect. Models were fitted using restricted maximum likelihood (REML).
